# Project Maturity

This document separates implemented evidence from future direction so the public showcase does not overstate the project.

## Implemented / validated today

- deterministic Python simulation and rule-engine behaviour;
- automated scenario and regression validation;
- architecture and human-review models;
- configurable sensing/topology representation;
- provenance-aware configuration handling;
- bounded Arduino-based bench-hardware validation;
- serial communication/integration work;
- controlled field-design and site-readiness analysis;
- procurement and professional installation of a small passive multi-camera CCTV field baseline;
- functional verification of local recording, wired transport, and operator viewing.

## In active development

- cybersecurity and commissioning hardening of the passive field baseline;
- least-privilege access and remote-administration design;
- recording/storage and maintenance verification;
- controlled field observation and placement validation;
- continued privacy, occlusion, and readiness analysis.

## Future / gated direction

- later perception/edge-compute experiments using approved passive field inputs;
- further verification experimentation;
- simulation and feasibility work for passive aerial verification;
- any real aircraft integration only after separate engineering, safety, legal, privacy, and operational gates.

## What is intentionally not claimed

This showcase does not claim a production household security product, live biometric identification, autonomous threat determination, autonomous physical response, or active drone flight.

The passive CCTV installation is a field-engineering baseline, not evidence that the autonomous decision stack is deployed.

The project's value is in the engineering progression:

**simulation -> software validation -> bounded hardware -> field design -> passive sensing baseline -> controlled hardening/observation -> later gated autonomy research**.
